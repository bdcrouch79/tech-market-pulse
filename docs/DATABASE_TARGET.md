# Database Target

Tech Market Pulse does not currently use a database.

- Supabase project: none
- Supabase schema: none
- migrations: not applicable
- persistent user data: none

All current dashboard metrics are calculated from external daily market-price data at request time. Do not introduce a database unless a future product requirement needs durable state such as user watchlists, saved snapshots, scheduled reports, or historical precomputation.
